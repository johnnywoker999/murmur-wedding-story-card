# 婚禮故事採集卡｜默墨文創

給新人填的婚禮影片故事採集卡。五幕（相識／相知／確認／相伴／承諾）＋加減項＋音樂＋備註，填完按「複製故事卡」，透過 LINE 等方式傳回製作方即可。**不上傳照片、不收集手機號、不向後台提交**，文字草稿只存在填寫者自己的瀏覽器。

- 線上使用：<https://aaronyi97.github.io/wedding-video-guided-wizard/> 的繁中台灣用語版  
  （本 repo 部署後的網址見 GitHub Pages 設定）
- 語言：預設繁體中文（台灣）；右上角可切 English；`?lang=zh` 可看簡中原版
- 手機、電腦都可以填，建議用電腦

## 這份卡片在流程中的位置

它是「婚禮影片 14 步流程」的第 1 步。填完的輸出（故事卡文字＋原圖）是後續文案、旁白、分鏡的唯一事實來源：**可以演繹表達，不能虛構經歷**。

## 技術說明

- 單一 `index.html`，無建置、無後端、無外部依賴，可直接放任何靜態空間
- 語言切換用字典對照（`EN`／`TW`），原文（簡中）保留為 key，故事卡輸出也跟著語言走
- 字型：`Noto Sans TC` / `PingFang TC` / `Microsoft JhengHei`
- 深色模式跟隨系統
