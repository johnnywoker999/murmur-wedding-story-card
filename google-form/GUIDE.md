# Google 表單版｜婚禮故事採集卡

同一份採集內容（五幕、24 個題目項目、18 題必填）做成 Google 表單，好處是**回覆直接進試算表**、不會有人忘記「複製貼回」、也不會貼到格式跑掉。

## 建立方式（約 2 分鐘，不用碰 API 金鑰）

1. 開 <https://script.google.com/home> → 「新增專案」
2. 把 `Code.gs` 全部貼進去，覆蓋原本的內容
3. 上方函式下拉選 **`createWeddingStoryForm`** → 按「執行」
4. 首次會跳出授權：選同一個 Google 帳號 → 「進階」→「前往（不安全）」→ 允許
   （會要「查看、編輯、建立及刪除你的 Google 表單」權限，這是 Apps Script 跑表單 API 的必要範圍）
5. 下方「執行記錄」會印出：
   - 填寫連結（發給新人）
   - 編輯連結（自己改題目）
   - 回覆試算表網址

重複執行會再建一份新表單，不會動到舊的。

## 與 14 步流程的接法

| 這份表單 | 對應 skill 步驟 |
|---|---|
| 送出表單 | 第 1 步「故事採集」完成 |
| 試算表那一列 | 整理成 `FACTS.md` 的原料（新人原話優先，不改寫事實） |
| 回傳故事卡給新人確認 | 第 3 步的依據（AI 整理版要讓新人確認，不是只信表單原文） |

⚠️ 表單原文**不等於**已確認文案。`FACTS.md` 由製作方整理後仍要回傳新人確認，這是流程裡不能省的一關。

## 與網頁卡的差異

| | 網頁卡（GitHub Pages） | Google 表單 |
|---|---|---|
| 品牌感 | 可完全自訂（默墨文創抬頭、字體、配色） | 只能改標題與說明，樣式是 Google 的 |
| 回覆收集 | 新人要「複製故事卡」再用 LINE 貼回 | 直接進試算表，一列一單 |
| 照片 | 一律走 LINE | 可開「檔案上傳」，但**要求填答者登入 Google**（多一層摩擦，建議不開） |
| 資料位置 | 新人自己的瀏覽器草稿 | 你的 Google Drive |
| 適合 | 想要品牌質感、單量少 | 單量多、要集中管理、要拿去算流程 |

## 已知取捨

- 表單不能做「一題一行的故事卡摘要」。要那段文字，就用網頁卡；要整齊的資料列，就用表單。
- 第 19 題（想放進去的東西）在網頁卡是「勾選＋各自填細節」，表單只能用多選＋「其他」一欄，細節請新人寫在「其他」。
- 第 6-2 題（畫風裡兩人怎麼出現）在網頁卡是選了非寫實畫風才出現；表單沒有條件顯示，所以做成選填並在說明寫清楚「選寫實電影感可留空」。
- 檔名／題號刻意與網頁卡一致（1、2-1、2-2、4、5、6、6-2、7–23），兩邊對照時不會錯位。
